# Temporary files

Convenient functions to create temporary file with a given extension.

## Usage

``` r
temptif()

tempgpkg()

tempshp()

templas()

templaz()

temppcd()
```

## Value

string. Path to a temporary file.

## Examples

``` r
tempshp()
#> [1] "/tmp/RtmpdBtwSW/file236857d999e.shp"
templaz()
#> [1] "/tmp/RtmpdBtwSW/file236821732594.laz"
```
